# Website settings

Typography decisions for `index.html`, set by AU.

- **Descriptions** (`.book-desc`, `.book-review-text`, `.work-desc`): bio typeface. Bodoni Moda (`--font-display`), `calc(17px + var(--text-bump))`, weight 400, line-height 1.6, max-width 62ch.
- **Description color:** `#c4c2bc`. Bio text (`.bio-text p`) stays `--offwhite`.
- **Titles** (`.writing-title`, `.book-title`, `.featured-title`): 2pt above their base size, `calc(<base> + var(--text-bump) + 2pt)`.
- **Sitewide:** `--text-bump: 2pt` is added to every font size.
- **Unchanged by choice:** `.writing-meta` and `.course-desc` stay IBM Plex Mono.
